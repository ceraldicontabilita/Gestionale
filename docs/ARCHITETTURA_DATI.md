# Autorità delle fonti

Impresa Semplice usa relazioni bidirezionali senza duplicare l'autorità del dato.

- documento fiscale: fonte del contenuto dichiarato/documentato;
- movimento bancario o carta reale: fonte del fatto finanziario;
- XML RT: fonte fiscale del corrispettivo;
- chiusura POS: fonte del transato del terminale;
- snapshot ADER: fotografia della situazione debitoria alla data di acquisizione.

Un collegamento rende i dati navigabili, ma non autorizza una fonte a riscriverne un'altra.
