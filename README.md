# Impresa Semplice

Nuova applicazione amministrativa indipendente.

> `ceraldicontabilita/GestionaleCloud` è esclusivamente una fonte di riferimento per parser, formati documentali e regole operative. Questo progetto non dipende dal vecchio gestionale e non ne modifica il codice.

## Principi

- frontend semplice: HTML, CSS e JavaScript senza framework;
- backend minimale Node.js/Express;
- persistenza MongoDB;
- motore documentale centralizzato;
- nessuna riconciliazione bancaria inventata: il movimento reale è la prova del pagamento;
- operazioni ambigue o non provate restano `DA_VERIFICARE` / Provvisoria;
- Cassa, Banca, Mastercard, Salari, Finanziamenti soci, SumUp, F24, cedolini e assegni mantengono fonti e regole distinte.

## Stato

Bootstrap iniziale del nuovo progetto.
